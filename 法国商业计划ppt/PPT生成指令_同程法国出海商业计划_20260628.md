# PPT生成指令｜同程旅行法国出海项目商业计划

## 任务目标

请根据以下指令生成一份适合公司高管立项汇报的中文PPT。

- 汇报主题：同程旅行法国出海项目商业计划
- 汇报目标：申请法国短途周末游动态打包项目正式立项
- 汇报时长：20分钟
- 页数：15页
- 受众：公司高管、战略负责人、财务负责人、国际业务负责人、产品/技术负责人
- 语气：高管汇报、战略清晰、结论先行、商业计划风格
- 视觉风格：现代咨询风、深蓝/白/浅灰为主色，少字、多图表、强结构
- 页面原则：每页只保留1个标题结论 + 1个核心视觉 + 3-5个关键词/短句；详细解释放入演讲备注

## 全局禁止事项

生成PPT时不要出现以下内容：

1. 不要提华人/留学生作为冷启动用户。
2. 不要提小红书、微信等中国渠道。
3. 不要提AI工具作为产品核心卖点。
4. 不要提露营作为业务方向。
5. 不要把产品说成固定套餐或跟团游。
6. 不要把页面做成大段文字版Word文档。
7. 不要强调低价平台心智；折扣只能作为转化工具，不作为品牌定位。

## 核心商业主张

法国本地短途周末游需求真实，但用户完成一次周末游需要在交通、住宿、体验和保障平台之间反复切换。现有平台强在单品，缺少围绕“短途周末游”的动态组合交易层。同程可复用酒店供应链、机票/交通能力、支付/订单/客服中台，并结合SNCF、Kombo、GetYourGuide、律所和本地营销公司的外部资源，从巴黎单城启动，推出“交通 + 酒店 + 体验 + 保障”的动态打包产品，第一年用约500万人民币预算验证巴黎MVP并复制到Top5出发城市。

## 必须突出的一句话

我们不是在法国重做一个泛OTA，而是用同程已有交易和供应链能力，切入法国本地短途周末游这个具体、高频、可验证的场景。

## 关键事实与口径

- 首发市场：法国本地短途周末游
- 首发城市：巴黎
- 年内扩展：巴黎、里昂、马赛、图卢兹、尼斯 Top5出发城市
- 路线范围：从巴黎出发，飞机/火车1-3小时以内，可完成周末往返
- 目标用户：五大都市圈25-45岁青年上班族，有稳定收入和短途周末出行意愿
- 产品形态：动态打包，不是固定套餐
- 产品入口：首页灵感推荐 + 用户主动搜索
- 动态模块：交通/火车、交通/飞机、酒店、体验、保障
- 首年预算：约人民币500万元，按阶段拨付
- 财务口径：采用中立档假设
- 外部合作基础：SNCF可合作接API并用折扣票；Kombo可提供交通货源；GetYourGuide可提供门票和体验产品；律所和营销公司已联系
- 内部可复用资源：同程酒店供应链、机票/交通能力、支付/订单/客服中台
- 保险：待定，可选增值模块，不作为MVP硬阻塞

# Slide 4｜为什么是短途周末游

## 页面标题
短途周末游是更适合首期验证的切口

## 页面展示文字
| 维度 | 长线度假 | 短途周末游 |
|---|---|---|
| 决策 | 慢、复杂 | 快、易触发 |
| 组合 | 个性化高 | 标准化更强 |
| 频次 | 低 | 更高 |
| 扩张 | 跨区域复杂 | 单城交通圈复制 |

底部：巴黎MVP → Top5城市复制

## 视觉指令
左侧放对比表，右侧放扩张箭头：Paris → Lyon / Marseille / Toulouse / Nice。加入“TGV/TER 1-3h圈层”或“1-3h by train/flight”示意。

## 演讲备注
短途周末游比长线度假更适合作为法国业务的第一个切口。第一，决策周期短，用户更容易被首页灵感触发；第二，产品结构相对标准，通常是交通、住宿、体验几个模块组合；第三，复购频率比年度长假更高；第四，城市复制路径更清晰。我们可以先做巴黎周边和从巴黎出发的1-3小时目的地，如果验证有效，再复制到里昂、马赛、图卢兹、尼斯。

# Slide 7｜竞品格局与市场空白

## 页面标题
竞品强在单品，缺口在组合逻辑

## 页面展示文字
| 平台 | 强项 | 缺口 |
|---|---|---|
| Booking / Airbnb | 住宿强 | 不组合交通 |
| SNCF / Kombo | 交通强 | 不组合住宿体验 |
| GetYourGuide | 体验强 | 不承接交通住宿 |
| Lastminute | 长线灵感/打包 | 无火车+酒店核心组合 |
| Verytrain | 火车+酒店 | 新平台；酒店先行，不符合交通先行顺序 |

底部结论：我们的差异化 = 交通先行 + 动态打包 + 可替换模块。

## 视觉指令
优先做2x2矩阵，不要只做大表。横轴：单品交易 → 组合交易；纵轴：信息灵感 → 支付履约。矩阵中标注Booking、Airbnb、SNCF、Kombo、GetYourGuide、Lastminute、Verytrain和“我们”。Verytrain作为直接竞对单独标注。

## 演讲备注
竞品分两类。第一类是强单品平台，比如Booking、Airbnb、SNCF、Kombo、GetYourGuide，它们分别解决住宿、交通、体验，但没有围绕一次周末游做完整组合。第二类是更接近组合逻辑的平台。Lastminute可以参考它的灵感货架，但它更偏长线度假，而且没有火车票+酒店这个核心组合。Verytrain是更直接的竞对，它已经做火车票+酒店，但平台还新，用户规模有限；更重要的是，它的交叉产品偏酒店先行，而法国短途出行通常是先确认交通是否可行，再决定住宿。我们的差异化就是交通先行、动态打包、模块可替换。

# Slide 11｜商业模式与中立档财务逻辑

## 页面标题
收入结构：佣金 + 打包收益 + 保障辅营

## 页面展示文字
中立档关键假设：
- 新客成本：€60 → €15
- 自然流量：5% → 55%
- 付费转化：1.8% → 4.5%
- 90天复购：5% → 28%
- 酒店佣金：约13%
- 火车净佣金：约0.5%
- 打包加价率：约1% → 3%

## 视觉指令

## 演讲备注
财务页采用中立档，不在PPT里堆完整P&L。高管真正需要看到的是模型逻辑和关键变量：获客成本能否下降，自然流量能否提升，动态打包占比能否起来，复购能否成立。收入结构上，第一层是火车、酒店、体验等单品佣金；第二层是机+酒、火+酒动态打包收益；第三层是取消险、旅行保险等保障类辅营。保险部分先作为财务模型假设，后续等保险合作方确认报价和责任边界后再校准。
